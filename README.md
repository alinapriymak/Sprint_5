## 📖 Описание проекта

Проект содержит набор UI-автотестов для проверки функциональности учебного сервиса «Доска». Тесты написаны с использованием **Selenium WebDriver** и **pytest**.

### 🎯 Цель проекта
- Автоматизация проверки критического функционала сервиса
- Обнаружение и документирование дефектов
- Обеспечение стабильности работы приложения

## ⚙️ Требования

### Программное обеспечение
- **Python 3.9+**
- **Google Chrome** (последняя версия)
- **ChromeDriver** (совместимый с версией Chrome)

### Установка ChromeDriver
1. Определите версию Chrome: `chrome://settings/help`
2. Скачайте ChromeDriver с [официального сайта](https://chromedriver.chromium.org/)
3. Добавьте chromedriver в PATH или поместите в папку проекта

## 🚀 Установка и запуск

### 1. Клонирование репозитория
```bash
git clone <repository-url>
cd Sprint_5
```

### 2. Установка зависимостей
```
pip install -r requirements.txt
```

### 3. Настройка тестовых данных
В файле utils/generate_data.py укажите реальные учетные данные существующего пользователя:

TEST_USER_EMAIL = "your_email@example.com"

TEST_USER_PASSWORD = "your_password"

### 4. Запуск тестов
Запуск всех тестов:
```
pytest tests/ -v
```

Запуск конкретного тестового файла:
```
pytest tests/test_registration.py -v
```

Запуск с подробным выводом:
```
pytest tests/ -v -s
```

Запуск с HTML-отчетом и сохранением в папку reports:
```
pytest tests/ -v --html=reports/report.html --self-contained-html
```
